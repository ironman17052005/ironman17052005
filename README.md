# Hey, I'm Clark

Second-year CS student at the University of Houston, and co-founder of Homefolk.
I build things that ship.

## What I'm working on

**[Homefolk](https://homefolk.ai)** — AI-powered assistant platform with multi-agent orchestration, tool execution, and real-time streaming. Built with React, TypeScript, Supabase, and Vercel.

**[YouStory](https://youstory.org)** — A permanent Wikipedia-style page for anyone. Write your own article, control every paragraph. Stripe integration, SSR, full-text search. Built with React 19, Vite 6, Tailwind v4, TanStack Query.

**i'm down** — A feed of outings real friend groups actually did. Tap one, and when enough of your friends are down, it proposes a hangout with times to vote on. The rules that matter — who can see your interest, when a plan becomes real, who can settle it — live in Postgres, not the UI, and are tested against a real database. *Private while I test it with real friend groups.*

**CapCrash** — 2D physics game with a custom physics engine. Collision detection, rigid body dynamics, and real-time rendering.

## Tech I use
